# Financial Transaction Analyzer

A terminal-based financial analysis application built using Python. The purpose of this project is to track income and expenses, analyse spending patterns, monitor budgets and generate financial reports.

I developed this project to strengthen my understanding of Python and apply programming concepts to practical financial and business problems.

## Features

- Record income and expense transactions
- Automatically generate transaction IDs
- View and search financial records
- Calculate total income, expenses and net savings
- Calculate savings percentages
- Analyse spending by category
- Identify the highest and lowest expenses
- Set and monitor monthly category budgets
- Identify potential duplicate transactions
- Flag unusually large transactions for review
- Generate consolidated financial reports
- Validate user inputs and transaction dates

## How to Run

1. Download or clone the repository.
2. Make sure Python 3.10 or newer is installed.
3. Open the project folder in VS Code.
4. Run the following command:

`python main.py`

## Testing

The application was tested against 20 automated test cases covering financial calculations, transaction storage, input validation, budget monitoring, duplicate detection, search functionality and menu navigation.

All 20 tests passed using Python 3.13.5.

To run the tests:

`python -m unittest -v`

## Current Limitations

- Transactions and budgets are stored in temporary memory.
- Financial records must be entered manually.
- The application currently supports PKR only.
- Financial calculations use floating-point arithmetic.
- Duplicate transactions are flagged but not automatically removed.
- Transactions of PKR 100,000 or above are flagged for review. This does not establish fraudulent activity.
- Reports are displayed in the terminal rather than exported.
